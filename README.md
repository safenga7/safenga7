## 🚀 Featured Project

### 🎬 Production AI Video Generation Pipeline

A production-oriented AI pipeline that transforms a user prompt into a complete generated video through a multi-stage automated workflow.

**What I built:**

- ⚙️ Python + FastAPI backend
- 🧠 Integration with multiple external AI APIs
- 🎬 AI image and video generation workflows
- 🗣️ TTS, music and sound-effect generation
- 🎞️ FFmpeg-based media processing and final assembly
- 🔄 Asynchronous job execution
- ♻️ Retry, cancellation and resume mechanisms
- ✅ Media validation and failure handling
- 💾 SQLite-based job state management
- 🐳 Dockerized deployment
- 🖥️ Linux VPS production environment
- 📊 Dashboard for job monitoring and generated outputs

> The production repository is private because it contains client work.
